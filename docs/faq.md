# FAQ

Q: What is Felis?
A: Felis is a source language that compiles into Scratch 3.0 projects. It is designed to help build larger Scratch projects using standard programming workflows.

Q: Do I need to use Scratch to use Felis?
A: You do not need the Scratch editor to write Felis source, but testing the generated `.sb3` in the Scratch editor or the Scratch player is recommended.

Q: Can I publish Felis projects to the Scratch website?
A: Generated `.sb3` files can be uploaded to Scratch if they comply with Scratch community guidelines.

Q: Where do I report bugs?
A: Open an issue on GitHub: https://github.com/Felis-Language/Felis/issues
